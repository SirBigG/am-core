# Domain: Пошук і знаходження ресурсів

## Мета

Користувач знаходить відповідні публічні ресурси AgroMega через один запит,
бачить тип кожного результату та переходить на наявну канонічну сторінку.

## Правила поточної реалізації

- Єдина видача охоплює матеріали каталогу, категорії/хаби, оголошення,
  Агромаркет, компанії та події.
- Реєстр сортів і щоденники виключені з пошуку за рішенням користувача
  2026-10-18. Це також виключає реєстрові назви як пошукові псевдоніми статей;
  самі розділи та їхні дані збережені.
- Новини та спільнота мають окремих власників даних; їх підключення —
  наступні етапи. Поточна видача ще не є пошуком по всіх сервісах.
- «Усе» змішує типи за релевантністю; вкладки дозволяють звузити видачу.
  Точна назва має пріоритет над згадкою у тексті та нечітким збігом.
- Приватний або прихований матеріал не з'являється навіть для авторизованого
  адміністратора. Майбутні публікації, неактивні категорії та їхні нащадки
  виключені; для оголошень діє строк активності.
- Маркет показує одну картку каталожної сутності з актуальними пропозиціями.
  Продавці не створюють однакових карток на кожен товар; ціни різних валют
  не змішуються. Пошуковий збіг не є підтвердженням товарної ідентичності
  або фактичної наявності у продавця.
- За замовчуванням шукаються майбутні/поточні події. Позначка архіву
  перемикає тільки події на минулі.
- Особисті поля, контакти, налаштування парсера та приватні записи не шукаються.
- Перехід між сторінками чи типами не рахується як новий пошук.
- Приховування та закінчення строків діють одразу через перевірку джерела;
  нові назви й тексти стають доступними після фонового оновлення індексу.

## Межі якості

Відкат через `UNIFIED_SEARCH_ENABLED=0` повертає стару видачу лише матеріалів,
але зберігає перевірку статусу, дати публікації, канонічного URL й активності
всіх предків категорії. В обох режимах запити обмежені 255 символами,
відповіді мають `no-store` і `noindex,follow`.

Підтримуються текстові збіги, частини назв і схожі назви з помилками.
Повноцінна українська морфологія, контрольовані синоніми, транслітерація
та редакційна оцінка великого набору запитів ще не реалізовані.
